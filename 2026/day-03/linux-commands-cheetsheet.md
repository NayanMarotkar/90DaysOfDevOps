*** COMMANDS CHEETSHEET ***

## Process Management - 
1. top - provide real-time dynamic view of running process and display all resource usage.
2. ps - list current running processes.
3. htop - it s improved version of top command with more user friendly interface.
4. jobs - list the processes that are running in backgroung or stopped in current terminal.
5. kill - used to kill running processes. using PID of process.
6. nohup - runs a command in the background allowing it to continue run even after user logs out.
7. atop - advanced performance monitor.
8. pgrep - find process by PID name.
9. pstree - view process hierarchy.
10. killall - kill processes by name.
11. pkill - kill processes using pattern.
12. bg - resume the jobs in the background.
13. nice start process with priority.

## File Management - 
1. ls - list files and dir.
2. cd - change dir.
3. pwd - show current dir path.
4. cp - copy files and dir.
5. mv - used for moving file and also to rename.
6. rm - remove files.
7. mkdir - create dir.
8. rmdir - used to remove empty dir.
9. cat - used to view file content.
10. find - search files by name, date etc.
11. du - display disk usage by dir.
12. df - display disk space usage.

## Networking troubleshooting -
1. ip addr - shows ip address.
2. ip route - used for ip routing table.
3. hostname - check hostname 
4. ping - useed to check connectivity and latency.
5. dig - dns query tool.
6. curl - used to check api and service health check
7. wget - to download from internet
8. nslookup - used for simple dns check.
