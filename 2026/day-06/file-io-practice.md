basic read write command practice notes

touch - create file using touch 
> - write or store the text using > in file.
>> - used to append text in the file as to not overwrite the content of the file.
tee - command used to store the output and also display at the same time. it is also called filtering command.
cat - used to read the file and check it's content.
head - used t check first lines like top 5 lines in files and not all the data.
tail - used to check last lines in the file.

It is important in devops as you have to read logs, scripts and store the error in the files if you need so the fundamentals must be clear and you should be proficient in it.
