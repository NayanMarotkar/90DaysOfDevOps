Day 08 – Cloud Server Setup: Docker, Nginx & Web Deployment

Key Commands used -
1. apt-get update - update your machine
2. apt-get install nginx -y - install nginx using package manager
3. systemctl status nginx - check if service is running or not.
4. curl - curl to your site to check if it is up or not
5. cat - to check logs of nginx in /var/log/nginx/access.log

what I learned -
1. how to deploy live web server aws ec2 server.
2. when you deploy nginx you should check if service is running or not.
3. check you have configured security group and allow http access for nginx.
4. saved nginx logs in nginx.logs and download on local using scp command
